# 🎮 PS Lounge

> **Premium Gaming Room Booking Platform**

**PS Lounge** — сучасний вебзастосунок для онлайн-бронювання Gaming Rooms, створений на **Django**. Проєкт поєднує стильний інтерфейс, зручну систему бронювання та функціонал для керування користувачами, оплатами, відгуками й інтерактивною JavaScript-мінігрою.

---

## ✨ Основні можливості

* 🔐 Реєстрація та авторизація користувачів
* 👤 Особистий кабінет
* 🎮 Каталог Gaming Rooms
* 🕹️ Вибір ігор для бронювання
* 📅 Онлайн-бронювання кімнат
* 💳 Імітація оплати
* ❤️ Система улюблених
* ⭐ Відгуки та рейтинги
* 💬 Чат між користувачами
* 🏆 JavaScript-мінігра та таблиця рекордів
* 🛠️ Адміністративна панель

## 🚀 Встановлення

### 1. Клонування репозиторію

```bash
git clone <repository-url>
cd PS-Lounge
```

### 2. Створення віртуального середовища

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 4. Виконання міграцій

```bash
python manage.py migrate
```

### 5. Запуск сервера

```bash
python manage.py runserver
```

Після запуску відкрий у браузері:

```text
http://127.0.0.1:8000/
```
